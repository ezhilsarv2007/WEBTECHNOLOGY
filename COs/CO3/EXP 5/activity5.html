Fallback Strategy

A cross-browser webpage should continue working even when a browser does not support a modern feature. This activity demonstrates three fallback approaches.

LocalStorage Uses temporary JavaScript memory when persistent storage is unavailable.
DOM Selection Uses getElementById() as a simpler alternative when querySelector() is unavailable.
CSS Enhancement Provides ordinary styling first and applies modern effects only when supported.
